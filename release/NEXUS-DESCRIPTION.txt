[size=5][b]Ironbound — HUD and Quality of Life[/b][/size]
A configurable Valheim interface and quality-of-life overhaul by KernelPanic.

[b]Version 0.5.6 — public alpha[/b]
Formerly Ragnarök. Remove old Ragnarok.dll copies before installing Ironbound.dll. Existing settings import on first start if no Ironbound config exists; mount bonds and progression remain compatible. The F10 window now shares the HUD's charcoal, iron and gold frames.
Builds and automated regression checks pass. The latest visual changes and every multiplayer/mount ownership scenario have not all received in-game testing. Back up your saves and begin with a test world.

[b]Features[/b]
[list]
[*]Rune & Iron HUD with character portrait, food beside Forsaken power, grouped buffs and debuffs below the compass.
[*]Custom inventory and crafting panels, recipe search, equipment/provision slots, sorting and a weapon dial.
[*]One nearby-storage feature for crafting, building, manual station supply, quick stack and chest search, sharing a range and access checks.
[*]Separate pickup/recipe/milestone notifications, crosshair ammo, loaded tame-animal dots and health/stamina regeneration numbers.
[*]One bound saddled mount per player. Summon the original animal onto safe outdoor ground, including from unloaded areas.
[*]Riding-based summon stamina and XP, modest temperament randomness, and server-controlled combat/safety rules.
[*]F10 configuration, personal HUD choices, synchronized shared gameplay rules and selected English/Turkish interface text.
[/list]

[b]Requirements[/b]
Valheim (compiled against 1.0.20), BepInExPack Valheim 5.4.2351, Jötunn 2.30.2 or newer.
Install dependencies separately. Install the same Ironbound version on the server and all participating clients for shared gameplay features. This is a plugin, not a modpack; no other mods are bundled.

[b]Install[/b]
Close the game/server. Extract the main archive into your Valheim folder so the plugin is at BepInEx/plugins/Ironbound/Ironbound.dll. Managed profiles use the profile folder instead. Keep only one copy: remove older DLLs from both plugins and scripts. Restart after updating. ScriptEngine is not required.

Press F10, then HUD > Style > Ironbound to enable the custom interface. Vanilla is the default. Hold Shift+H near a tamed saddled mount to bind/release; press H outdoors to whistle. Default provision shortcuts are Alt+4/5/6. Rebind controls in F10.

[b]Mounts[/b]
Summoning preserves the same animal, health and saddle. It does not heal, clone or revive it. Your mount stays where left after portals. Combat, riders, wards and unsafe arrival locations can block a summon. Stamina is charged only after confirmed arrival; Riding lowers the cost from 10% at level 0 to zero at 100. Hungry/frightened mounts may occasionally delay or refuse; refusal costs no stamina and grace prevents repeated bad rolls. The included MOUNTS.md documents exact rules and limits.

[b]Compatibility and removal[/b]
Arbitrary mod combinations, Linux runtime and Vortex deployment are not verified for this alpha. Prefer testing in a separate profile. Before removing Ironbound, move items out of added equipment/provision/inventory slots into ordinary inventory or chests, save, and quit. Back up saves before updating or removing.
