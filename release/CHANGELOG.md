# Ironbound 0.5.6 alpha

- Rename Ragnarök to Ironbound across the plugin, source projects, UI, repository
  and distribution. New plugin GUID/config filename and DLL include legacy config
  import; mount, receipt and reclaim identifiers remain compatible.
- Redesign F10's frame, cards, buttons, fields and toggles with quiet charcoal
  surfaces, thin iron edges and restrained gold accents matching the HUD.

Public alpha package of the current development build. Original code is
MIT-licensed; issues, testing reports, translations and pull requests are welcome.

- Rune & Iron HUD, inventory/crafting panels, weapon dial and provision slots.
- Unified nearby-chest crafting, building, station supply, quick stack and search.
- Native status/food icons, grouped buffs/debuffs, crosshair ammunition and tame dots.
- Separate item pickup, recipe and skill milestone notifications.
- Expanded map draws above the custom HUD and windows.
- Numeric health/stamina regeneration readouts beside their respective bars.
- Server-authoritative mount bonds with stable animal identity, distant summons,
  Riding-based stamina/XP, restrained random temperament and arrival effects.
- Server gameplay configuration synchronization and reload/unload cleanup.
- Remove legacy embedded power PNGs without recorded provenance from current
  source/builds; power displays resolve the installed game's icons at runtime.

Builds, metadata, configuration migration and regression suites pass. Latest visual
changes and all multiplayer/mount scenarios still need live verification. Linux
runtime and Vortex deployment have not been verified for this release.
