## Original artwork

The package's charcoal/gold rune icon is drawn from original geometric paths by
scripts/make-release-icon.ps1; it uses no external imagery or font glyphs.
The inventory shield path was supplied by the project owner. Other theme shapes
are procedural project UI geometry. No asset bundles are included.
